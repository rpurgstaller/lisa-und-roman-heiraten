# RSVP & Guest Registration - Receive Invitation Access

As a guest, I want to access the website using a unique invitation so that only invited guests can register.

## Acceptance
- For each user, the invitation code is saved in the database
- Guests can log in using an invitation code or personalized link.
- Guests are informed if their invitation code is invalid
- Guest identity can be validated
- When openening a invitation link, the following is displayed: "Hello " + User Name
